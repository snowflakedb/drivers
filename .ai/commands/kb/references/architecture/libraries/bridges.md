# The Bridge Crates

`jdbc_bridge`, `python_bridge`, and `nodejs_bridge` are the only code that crosses the FFI boundary. Each is a `cdylib` the host runtime loads, and each owns exactly two jobs: convert host-language values to and from protobuf, and expose the entry points that host's FFI expects. No driver behavior belongs here — that is [sf-core.md](sf-core.md).

They are documented together because they play the same role; they differ in FFI mechanism, in crate type, and in whether they ship extra tooling.

| Crate | Host | FFI mechanism | Notes |
|---|---|---|---|
| `jdbc_bridge` | JVM | `jni` crate — `JNI_OnLoad`, `extern "system"` entry points | `crate-type = ["cdylib"]` |
| `python_bridge` | CPython | `pyo3` with the `extension-module` feature, plus `pyo3-async-runtimes` on Tokio | `["cdylib", "rlib"]`; also ships `stub_gen`, which generates the `.pyi` stubs |
| `nodejs_bridge` | Node | `napi` v3 targeting the `napi9` ABI, built through `napi-build` | `crate-type = ["cdylib"]` |

`odbc` has no bridge crate: it is a workspace member that links `sf_core` directly, because the ODBC ABI is already C. `.NET` reaches the core through its own `Snowflake.Data.Proto` project rather than a Rust bridge.

## What a change here usually means

- **Adding data a wrapper needs** — change `protobuf/database_driver_v1.proto` first. A field added in one bridge alone never reaches the core. See [../../concepts/core-and-bridge-split.md](../../concepts/core-and-bridge-split.md).
- **A new connection parameter** — change `sf_params_spec`, not the bridge; the per-wrapper view is generated. See [../../concepts/connection-parameters.md](../../concepts/connection-parameters.md).

## Gotchas

- The host loads the built `cdylib` by path, so a bridge that was not rebuilt fails as a library-load error at test startup rather than as a test failure. The per-wrapper build step and its path variable are in that wrapper's `tools/` reference.
- `python_bridge/stub_gen` output (`sf_core_python.pyi`) is generated and regenerated by a pre-commit hook; do not hand-edit it.
