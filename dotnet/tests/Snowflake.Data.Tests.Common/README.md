# Snowflake.Data.Tests.Common

Shared test infrastructure consumed by both `Snowflake.Data.Tests` and `Snowflake.Data.Tests.Reference`.

This is an **executable** (`OutputType=Exe`) class library (`IsTestProject=false`) — xUnit will not discover tests here directly.

Uses xUnit v3 across all target frameworks (net8.0+, net472, net481).
